# CheatUtils - mod singleplayer (Fabric 1.21.11, mappingi Mojang)

Tylko do gry solo / na wlasnym swiecie. Nie uzywaj na cudzych serwerach.

GUI: RIGHT_SHIFT. LPM na module = wlacz/wylacz, PPM = rozwin ustawienia.

Moduly: KillAura, ESP (boxy + tracery przez sciany: gracze/moby/zwierzeta/dropy/storage),
Xray (podswietlone rudy przez sciany), AutoClicker, AutoFarm (A/D), Fullbright.

Build: patrz .github/workflows/build.yml (GitHub Actions) -> Artifacts -> cheatutils-jar.
